# Published assets

- `audio/doppler/`: Doppler teaching samples.
- `documents/articles/`: papers linked from current pages.
- `documents/brochures/`: numbered Guard Your Feet translations.
- `documents/clinical-tools/`: downloadable clinical references.
- `images/brand/`: wordmark, favicon, and identity assets.
- `images/home/`, `images/about/`, `images/works/`, `images/brochures/`, `images/tutorials/`, and `images/system-of-care/`: page-specific media.
- `js/`: small progressive-enhancement scripts.

Use lowercase kebab-case filenames. Keep source/editable files outside the published asset tree unless visitors need to download them.
